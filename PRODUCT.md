# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People using native AI agents for coding, research, and professional work who want one workspace, account, and visible working context across those agents.

## Product Purpose

Minaco brings supported native AI agents into one desktop workspace. Users choose an agent and an available model, work with local projects, and continue visible conversation context when switching agents.

## Positioning

Minaco preserves each agent's native runtime and account boundaries while providing a shared workspace, Minaco-funded model access, and explicit context handoff between agents.

## Operating Context

The public website explains Minaco, its agents, models, pricing, downloads, and account flows. The Desktop product works with local project files and native agent runtimes on macOS.

## Capabilities and Constraints

Model and agent availability comes from the live Desktop catalog. Minaco-funded usage consumes shared Credits at published token rates. Provider credentials, private reasoning, and live processes do not transfer between agents. Product claims and benchmark results must be sourced and must distinguish vendor evaluations from independent Minaco testing.

## Brand Commitments

The product name is Minaco. Public product UI and marketing copy are English. The voice is direct and evidence-led, avoiding invented capability or performance claims.

## Evidence on Hand

The repository contains the production landing experience, live model catalog integration, agent and model directories, signed download flow, Minaco brand assets, and reviewed Qwen4-Max source material supplied through the independent Minaco Desktop repository.

## Product Principles

- Preserve native agents instead of flattening them into generic chat wrappers.
- Keep local work and user-visible context continuous while maintaining credential boundaries.
- Publish exact model identities, current prices, and sourced performance claims.
- Make the next action—choose an agent, choose a model, or download Minaco—unambiguous.
