# Find the First 100 Seed Users

## Action

1. If the product is not known from the current message or conversation history, ask for it.
2. Treat a bare product name, domain, URL, app link, or short product description following that question as the target and continue without asking the user to repeat the task.
3. Define a qualified seed user, ICP, activation event, retention expectation, feedback requirement, and exclusions.
4. Rank a small set of reachable channels and build the funnel backward from 100 retained target users.
5. Propose short experiments with action, sample size, success threshold, stop condition, and learning objective.
